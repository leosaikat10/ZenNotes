# ZenNotes 🧠

A modern minimalist notes application built with React.

ZenNotes allows users to:
- Create notes
- Read notes
- Update notes
- Delete notes
- Search notes instantly
- Persist notes using Local Storage

Built for learning React fundamentals through a real-world CRUD project.

---

# Features ✨

- Modern minimalist UI
- Responsive layout
- Create / Read / Update / Delete notes
- Real-time search functionality
- Local Storage persistence
- Interactive editor panel
- Dynamic React rendering
- Clean component-based architecture

---
